## API de Dados Pessoais

**Em desenvolvimento**

API REST desenvolvida na disciplina de Desenvolvimento, utilizando Java e Spring Boot. O projeto tem como foco a implementação de operações CRUD, validação de dados, persistência com JPA/Hibernate e organização de aplicações back-end em camadas.

### Tecnologias

Java • Spring Boot • Spring Data JPA / Hibernate • H2 Database • Maven


### Funcionalidades

- Cadastro, consulta, atualização e exclusão de pessoas
- Validação de dados
- Tratamento de requisições HTTP
- Utilização de DTOs, Services, Controllers e Repositories

### Conceitos abordados

- Desenvolvimento de APIs REST com Spring Boot
- Anotações do Spring e injeção de dependências
- Métodos HTTP e mapeamento de endpoints
- Comunicação entre as camadas da aplicação
- Mapeamento objeto-relacional com JPA
